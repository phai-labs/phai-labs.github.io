The argument

01  /  The constraint

Intelligence has run out of internet.

Published data is static and already trained on. Synthetic reasoning only restates what a model already knows. Contract labs return a result with no task context and no training interface. The one input the frontier is short of — scientific data with a verified physical outcome attached — cannot be scraped. It has to be produced.

02  /  The loop

Data trains the model. The model designs the next experiment.

Dry  ·  hypothesis, trajectory, rubric Wet  ·  protocol, outcome, reward Coupled on Rubric × Task ID

A model's failures are the hypotheses worth testing. A rubric turns each one into a protocol with controls, thresholds and a stopping condition. What comes back from the bench — including every failure — returns as reward, as a harder benchmark, and as the next rubric. Two directions, so the returns compound rather than add: every cycle lowers the cost of the next unit of valid data.
